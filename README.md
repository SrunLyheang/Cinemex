
This is a website for Web development I class
🎬 Cinemex

Cinemex is a movie review website created as a group project by a team of 5. The website allows users to explore movies through different categories and discover popular and highly rated films.

✨ Features

* Browse movies by category
* Explore New & Popular movies
* View Top Rated movies
* Coming Soon section
* Interactive and responsive website design

🛠️ Tech Stack

* HTML
* CSS
* JavaScript

👥 Team

Cinemex was developed as a group project by 5 team members, with each member contributing to different parts of the website.

My Contribution

I mainly worked on the JavaScript, focusing on the website’s interactive features and functionality.

## 📁 Project Structure

- **HTML Pages**
  - `Index.html` — Main homepage
  - `New and Popular.html` — New and popular movies
  - `Top rated.html` — Top-rated movies
  - `Coming Soon.html` — Upcoming movies
- `styles.css` — Website styling
- `script.js` — JavaScript functionality
- **assets/** — Images and other project resources
