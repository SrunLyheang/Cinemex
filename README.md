
This is a website for Web development I class
🎬 Cinemex

Cinemex is a movie review website created as a group project by a team of 5. The website allows users to explore movies through different categories and discover popular and highly rated films.

✨ Features

* Browse movies by category
* Explore New & Popular movies
* View Top Rated movies
* Coming Soon section
* Interactive and responsive website design

🛠️ Tech Stack

* HTML
* CSS
* JavaScript

👥 Team

This project was developed collaboratively by 5 team members, with each member contributing to different parts of the website.


📂 Project Structure

Cinemex/
├── Index.html
├── New and Popular.html
├── Top rated.html
├── Coming Soon.html
├── styles.css
├── script.js
└── assets/

🚀 Getting Started

1. Clone the repository:

git clone https://github.com/SrunLyheang/Cinemex.git
